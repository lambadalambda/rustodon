# Stream public, hashtag, and list timelines

## Summary

Rustodon accepts only user, notification, and direct WebSocket subscriptions. The bundled Mastodon frontend also subscribes to public, local-public, media-only, remote-only, hashtag, local-hashtag, and list stream variants, so those visible columns appear connected but do not receive new posts or deletions until a REST reload or reconnect.

## Requirements

- Implement every Mastodon 4.6.5 stream generated by the bundled timeline UI: `public`, `public:media`, `public:local`, `public:local:media`, `public:remote`, `public:remote:media`, `hashtag`, `hashtag:local`, and `list`.
- Validate and authorize hashtag/list subscription parameters with the same visibility, block, mute, domain, and list-owner rules as corresponding REST timelines.
- Project create/update/delete events consistently across REST timeline membership and live streaming.
- Return protocol-compatible subscription errors instead of silently ignoring unsupported commands.
- Preserve bounded durable event history and reconnect behavior.

## Acceptance Criteria

- An already-open public/local/remote/media-only/hashtag/list column receives eligible creates, updates, and deletes without manual reload.
- Ineligible events remain suppressed under the corresponding timeline policy matrix.
- Unauthorized or malformed list/hashtag subscriptions fail explicitly.
- Browser coverage proves each bundled column updates live and reconnects without gaps or duplicates.

## Evidence

- Mastodon 4.6.5's streaming server declares and implements all nine channels in `target/mastodon-v4.6.5/streaming/index.js`; its frontend connectors derive the public local/remote/media variants and subscribe to hashtag/list streams without periodic polling fallback.
- Rustodon's `StreamName` and `ClientCommand` accept only `user`, `user:notification`, and `direct`. `src/web.rs` silently ignores unsupported dynamic commands.
- The result is an ordinary UI freshness failure rather than an obscure API gap: Live Feeds, hashtag timelines, and list columns can remain stale while they look connected.
